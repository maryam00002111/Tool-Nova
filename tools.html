PDF Tools

Compress PDF

Runs structural optimization (object-stream compression) to shrink file size. This pass doesn't recompress embedded images, so savings vary — heaviest on text-based PDFs.

PDF Unlock, PDF Protect, and PDF ↔ Word need either a password/encryption engine or a document-rendering engine that isn't reliable to run fully client-side yet — rather than ship a button that fakes it, they're staying off the site until they actually work.
